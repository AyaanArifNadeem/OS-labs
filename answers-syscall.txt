Q)Why does the kernel crash? Hint: look at figure 3-3 in the text; is address 0 mapped in the kernel address space? Is that confirmed by the value in scause above? (See description of scause in RISC-V privileged instructions)
Ans)The kernel crashes because it attempts to read from memory address 0 which is not mapped in the kernel's address space to intentionally catch null pointer dereference bugs. In the RISC-V privileged instruction set, an scause value of 0xd (or 13 in decimal) specifically means a Load Page Fault this confirms that the CPU crashed because it tried to load data from an unmapped page in memory.
